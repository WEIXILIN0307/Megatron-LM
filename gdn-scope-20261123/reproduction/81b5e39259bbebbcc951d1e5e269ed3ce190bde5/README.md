# Historical GDN reproduction tools

These files are archived byte-for-byte from source `81b5e39259bbebbcc951d1e5e269ed3ce190bde5`.
Run them from a checkout of that source with the dependencies recorded in the
original evidence. They are experimental saved-tensor profiling, local Qwen/Bridge,
tokenization and checkpoint harnesses, plus their tool-only tests. They are no longer
part of the GDN feature PRs. Their results do not qualify the revised PR heads.

The historical user document retains commands, runtime constraints and links to the
original data. Model weights, datasets and compiled dependencies are not included.
